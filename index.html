CMS Integration & Placement Guide

WordPress Integration

  1. Recommended: Install a header script plugin such as WPCode / Insert Headers and Footers or Code Snippets.
  2. Navigate to Code Snippets → Header & Footer.
  3. Paste the generated <script type="application/ld+json"> payload directly into the Header box.
  4. Alternatively, if using RankMath SEO or Yoast, navigate to the Schema tab and paste into Custom Schema.

Squarespace Integration

  1. From your Squarespace dashboard, go to Settings → Advanced → Code Injection.
  2. Paste the code into the Header textarea.
  3. For per-page schema (e.g. specific album or event pages in Multi-Page mode), click the gear icon on the specific page → Advanced → Page Header Code Injection.

Webflow Integration

  1. Open your project in the Webflow Designer.
  2. Navigate to Project Settings → Custom Code (for site-wide schema) or Page Settings → Custom Code (for per-page schema).
  3. Paste the code snippet inside the Inside <head> tag block and publish the site.

Wix Integration

  1. In your Wix dashboard, go to Settings → Custom Code under Advanced.
  2. Click + Add Custom Code.
  3. Paste the code snippet, choose Head for code placement, and set Apply to: All Pages (or Specific Pages).

Shopify / Merch Store Integration

  1. In Shopify Admin, go to Online Store → Themes → Edit Code.
  2. Open layout/theme.liquid.
  3. Paste the code snippet just before the closing </head> tag.

Static HTML / Apache / Nginx

Paste the snippet directly between the <head>...</head> tags or right before </body> on your static HTML template.
